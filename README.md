# 智能记账助手 (astrbot_plugin_accounting)

基于大语言模型（LLM）的智能记账、查账、财务状态分析与消费建议助手。本插件作为 AstrBot 的扩展，通过大语言模型的自然理解能力与 Tool Calling（工具调用）机制，为您提供私人理财助手般的体验。无需死板的指令，像和朋友聊天一样就能管好账。

## ✨ 核心功能

- **自然语言记账**：直接告诉它你花了什么、赚了什么，自动提取金额、用途并记录。
- **自动月度扣除**：设置每月的固定支出（如房租、分期），跨月首次使用时自动进行扣款，免去手动记账的烦恼。
- **预算控制与自定义预警**：设定月度日常消费预算，您可以在插件设置中**随意自定义多个预警阈值**（如输入 `20, 50, 80, 100`），当花销达到这些比例时它会自动发出提醒。
- **消费建议**：在你透露想买某样东西时，它会结合你当月的剩余预算和距离月底的天数，帮你“拔草”或给出合理的购买建议。
- **灵活查账**：支持自然语言询问“今天”、“这周”或特定时间段的账单流水。
- **多端持久化**：数据安全存储在 SQLite 中，无论你怎么重置对话或更换窗口，你的账本永远都在。

## 🚀 如何安装与开启

1. **放置插件**：将本插件文件夹（`astrbot_plugin_accounting`）放置在 AstrBot 项目目录的 `data/plugins/` 下。
   *(本插件使用 Python 内置库开发，**完全零依赖**，直接放入即可使用，不需要运行任何安装命令！)*
2. **重启/重载**：在 AstrBot 的 WebUI 管理面板中重载插件，或者直接重启 AstrBot 进程。
3. **模型要求**：本插件极度依赖大模型的 **Tool Calling（函数调用）** 能力。请确保您在 AstrBot 中选择并激活的模型支持工具调用（例如 GPT-4o, Claude 3.5 Sonnet, DeepSeek V3 等）。

## 💬 怎么用？(使用示例)

你完全不需要使用任何带有前缀（如 `/`）的死板指令，直接和机器人正常聊天即可。以下是一些常见的对话场景：

### 1. 初始化账本
第一次使用时，你需要告诉它你的初始本金。
- **你说**：`“帮我建个账本，我现在的总余额是 20000 块。”`
- **LLM 可能会回复**：`“没问题！已经帮你把账本建好了，现在的初始总余额是 20000 元。接下来有任何进出账，或者想设置每个月的预算和固定支出，随时跟我说哦~”`

### 2. 设定固定支出与预算
- **你说**：`“设置一下我每个月的固定房租水电支出是 2500，另外我这个月的日常消费预算是 1500。”`
- **LLM 可能会回复**：`“记下了。你每个月的固定扣除已经设置为 2500 元，日常消费上限也定在了 1500 元。以后每个月我会自动帮你扣除这笔固定支出，平时花钱要是快超预算了我会提醒你的。”`

### 3. 日常记账
- **你说**：`“刚打车花了 35 块。”`
- **LLM 可能会回复**：`“记录成功！打车花了 35 元，你现在的总余额变为 19965 元啦。这个月的生活费预算你已经用了 35 元，还剩 1465 元可以花。”`
- **你说**：`“今天发工资了，进账 8000。”`
- **LLM 可能会回复**：`“太棒了！工资 8000 元已经入账。你的总余额现在涨到 27965 元了！”`

### 4. 查账与查询余额
- **你说**：`“帮我查一下这周我都花了哪些钱？”`
- **LLM 可能会回复**：`“好的，帮你查了一下。你这周一共有两笔支出：周一打车花了 35 元，周三喝奶茶花了 20 元。总共支出了 55 元。”`
- **你说**：`“我还剩多少钱？”`
- **LLM 可能会回复**：`“你现在的总余额还有 27910 元。当月的 1500 元日常预算你已经花了 55 元，还剩 1445 元可用。离月底还有十几天，额度很充足哦！”`

### 5. 消费建议（核心亮点）
当你遇到想买但犹豫的东西时，可以直接问它。
- **你说**：`“我看上了一个 300 块的蓝牙耳机，你说我现在买合适吗？”`
- **LLM 可能会回复**：`“我帮你看了下账本，你这个月的日常预算还剩 400 块，要是现在买了耳机就只剩 100 块了！可是离月底还有足足 12 天呢，靠 100 块钱可能有点难熬。要不咱们先忍忍，等下个月预算更新了再买？”`

## 📝 更新日志

### v1.1.0
- **重构为子智能体 (Sub-Agent) 架构**：大幅提升大模型的工具调用速度，支持在设置面板中指定专用的“记账轻量模型”（如 `gemini-1.5-flash`），并在后台无缝将结果交由主模型生成最终回复。
- **自定义预算预警阈值**：预算控制更加灵活。您现在可以在设置面板中通过 `20, 50, 80, 100` 等格式，随意配置多个消费预算预警百分比，金额达到对应比例时将精准提示。
